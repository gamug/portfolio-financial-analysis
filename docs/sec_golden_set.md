## What the checklist expects, by type

| Choice | Expectation |
|---|---|
| Revenue, article_9 | the total net revenue concept (Revenues or RevenuesNetOfInterestExpense); no cost of sales (APP-01) |
| Revenue, article_7 | premiums plus investment income (APP-03); no cost of sales |
| Revenue, other_financial | the filed total revenue concept (CON-11); fees for managers and brokers |
| Revenue, operating | the filed total (Revenues / RevenueFromContractWithCustomer...) -- never a component (CON-11) |
| Capex, utility | PP&E payments (PaymentsToAcquirePropertyPlantAndEquipment); a utility's construction expenditures, no acquisitions (MET-08) |
| Capex, oil_gas | exploration & development, plus equipment lines when separate (MET-08 (c) tie-break); never mineral-interest purchases or business acquisitions (MET-08 (a)) |
| Capex, reit | corporate items + existing properties + development + acquisitions (APP-04b); PaymentsForCapitalImprovements never added to an acquisition line |
| Capex, financial | not applicable (APP-02b) |
| Capex, default | PP&E payments; productive assets only as a flagged fallback (MET-08) |
| Debt | narrowest long-term line first, current maturities not counted twice, operating leases excluded; the combined debt-and-lease element only when it is the only line, flagged (MET-07) |
| FFO | not computed for any REIT (L-02) |
